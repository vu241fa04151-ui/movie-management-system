# 🎬 Movie Management System

A simple and user-friendly **Movie Management System** developed as a web-based project. The application allows users to view and manage movie information through an interactive interface.

## 📌 Features

* 🎥 Display available movies
* ➕ Add new movies
* ✏️ Update existing movie details
* 🗑️ Delete movies
* 🔍 View movie information
* ⭐ Display movie ratings
* 🎭 Manage movie genres and languages
* 📅 Manage release years
* 🖼️ Display movie posters
* 📱 Simple and responsive user interface

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript** – Functionality and CRUD operations
* **JSON** – Movie data storage

## ⚙️ CRUD Operations

The project supports the basic CRUD operations:

| Operation | Description            |
| --------- | ---------------------- |
| Create    | Add a new movie        |
| Read      | View available movies  |
| Update    | Edit movie information |
| Delete    | Remove a movie         |

## 🎬 Movie Information

* Duration

* Poster

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/movie-management-system.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

### Recommended

If the project uses JavaScript to fetch data from a JSON file, run it using **VS Code Live Server** instead of opening `index.html` directly.
